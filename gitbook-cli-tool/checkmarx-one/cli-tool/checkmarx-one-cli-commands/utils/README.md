# utils

The `utils` command is used for performing various **Checkmarx One utility functions**.

## Usage

```
./cx utils [command]
```

## Help

- `---help, -h` — Help for the health-check command.

## Utility Commands

`utils` can be used with the following commands:

- [completion](completion.md)
- [env](env.md)
- [contributor-count](contributor-count/README.md)
- [learn-more](learn-more.md)
- [remediation](remediation/README.md)
- [pr](pr/README.md)
- [tenant](tenant.md)
- [mask](mask.md)
- [import](import.md)

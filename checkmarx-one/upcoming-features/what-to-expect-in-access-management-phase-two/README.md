# What to Expect in Access Management Phase Two

A more sophisticated and dynamic system is anticipated in Phase 2 of the Access Management evolution in Checkmarx One. This phase will introduce the ability to combine resource assignment with roles granted in the resource scope. The same user or group can have different roles within different resource domains.

Roles will no longer be uniform across all resources. Instead, administrators can combine and customize roles at the resource level. This level of adaptability will allow for a more nuanced and precise assignment of permissions.

The introduction of resource-specific roles signifies a shift towards a more refined and controlled access management strategy and a more dynamic and adaptive access management framework. This will allow our customers to evolve their access control strategies in response to changing project requirements, team structures, or security considerations.

The combination of resource assignment and customizable roles improves the user experience. Users can expect a more intuitive interaction with the system, as their roles are finely tuned to the specific tasks and responsibilities associated with each resource they engage with.

{% hint style="warning" %}
The new access management is only supported for CLI version 2.3.31 and above and for the the plugins that are based on the supported CLI. If the new access management is activated for your tenant account, make sure that you are using up-to-date CLI and plugin versions.
{% endhint %}

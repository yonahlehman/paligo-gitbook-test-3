**Application Risk Management**

| Permission Name | Description |
|---|---|
| Update | Allows updating specific columns in the Application Risk Management table at the application level |
| View Dashboard | Grants access to the organization's "Top 10 Most Risky Applications" dashboard. This permission is tenant-level only |
| View Tab | Permits viewing the detailed tab for applications the user is associated with. This permission works at the application level |

**Data Retention**

| Permission Name | Description |
|---|---|
| Abort | Allows the user to cancel an ongoing data retention process. |
| Start | Grants the user the ability to initiate a new data retention process. |
| View | Enables the user to check the status of current or completed data retention processes. |
| Lock Scans | Grants the user the ability to lock specific scans, preventing them from being deleted during data retention processes. |
| Update Locked Scans | Enables the user to lock or unlock specific scans, modifying their retention status during the data retention. |

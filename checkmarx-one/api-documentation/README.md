# Checkmarx One API Documentation

You can access the full functionality of Checkmarx One using our REST APIs. You can use APIs to perform CRUD actions on Checkmarx One Projects and Applications, run scans, and view scan results. You can also use APIs to manage vulnerabilities and create webhooks.

{% hint style="warning" %}
Documentation for the Checkmarx One external REST APIS has moved to a new location. The API Reference Guide is now available [here](https://checkmarx.stoplight.io/docs/checkmarx-one-api-reference-guide).
{% endhint %}

Container Security results can be accessed using GraphQL APIs, which are documented in the article [below](container-security-graphql-api-documentation.md).

# API Security Scanner - Supported Languages and Frameworks

**API Security** currently supports the following languages and frameworks:

- **Java - Spring**
- **ASP.NET - Web API**
- **Python - Flask**

For detailed information about the queries used for each language and the limitations that apply, see [API Security Language and Framework Support](../../user-guide/api-security/api-security-language-and-framework-support.md).

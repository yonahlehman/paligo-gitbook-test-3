# Applications Projects Table

The Projects table details all the projects that are assigned to the application.

The following table describes the info shown for each project.

| Item | Description |
|---|---|
| Project Name | The name of the project. |
| Risk Level | Project risk level (Critical High, Medium, Low, Info). |
| Tags | Shows tags in **key** or **key:value** pairs that were applied to this project. |
| Last Scan | Shows how much time has passed since the Project was last scanned. |
| Last Import | Shows how much time has passed since the Project was last imported. |
| Groups | Shows the groups that are assigned to the project. |
| Vulnerabilities Severities | Presents the vulnerabilities according to their severity (Critical High, Medium, Low, Info) |

# Domain Management

The **Domains** page in Account Settings lets you manage the list of domains that contributing developers are permitted to use within the platform. You can register up to 20 domains.

By default, the **Domains** list is empty. Until at least one domain is added, the table displays `No data` and the item count reads 0 total items. Each entry in the **Domains** table shows the domain value that has been added.

Use the **Search** field above the table to quickly locate a specific domain once you have several registered.

## Adding domains

To add a domain:

1. On the **Domains** page, click **+ Add Domain(s)**. A sliding panel opens on the right side of the screen.
2. In the **Domain(s)** field, enter the domain(s) you want to add. You can type a single domain or enter multiple domains separated by semicolons (;) to add several at once.
3. Click **Save** to add the domain(s) to the list, or **Cancel** to close the panel without saving.

Once saved, the new domain(s) appear in the **Domains** table and the total items count updates accordingly.

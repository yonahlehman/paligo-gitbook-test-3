# Using the Checkmarx Kiro Extension

The Kiro IDE is based on VS Code, and as such, the VS Code plugin works effectively in Kiro. The tools included in the extension work seamlessly in Kiro, and the usage and results of the extension are nearly identical to VS Code.

{% hint style="info" %}
Although there is no dedicated Checkmarx plugin for Kiro, the plugin for VS Code has been tested and found to be effective for use in Kiro.
{% endhint %}

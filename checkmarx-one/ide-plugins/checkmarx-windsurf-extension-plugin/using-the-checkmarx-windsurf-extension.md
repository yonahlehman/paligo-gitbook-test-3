# Using the Checkmarx Windsurf Extension

The Windsurf IDE is based on VS Code, and as such, the VS Code plugin works effectively in Windsurf. The tools included in the extension work seamlessly in Windsurf, and the usage and results of the extension are nearly identical to VS Code.

{% hint style="info" %}
Although there is no dedicated Checkmarx plugin for Windsurf, the plugin for VS Code has been tested and found to be effective for use in Windsurf.
{% endhint %}

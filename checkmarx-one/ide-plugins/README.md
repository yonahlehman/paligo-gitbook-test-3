# Checkmarx One IDE Plugins

We provide specialized plugins that enable you to seamlessly import Checkmarx One scan results into your favorite IDEs.

## Checkmarx One IDE Plugins Supported Features

The following table gives an overview of the supported features for each of the IDE plugins.

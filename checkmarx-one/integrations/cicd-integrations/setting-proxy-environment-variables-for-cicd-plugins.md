# Setting Proxy Environment Variables for CI/CD Plugins

You can direct your Checkmarx One calls through a proxy server. This is done by setting environment variables in your CI/CD platform for use with the Checkmarx One plugins. The procedures for configuring proxies for each of the plugins are described in the links below.

**TeamCity:** [Setting up a Proxy Environment Variable](checkmarx-one-teamcity-plugin/adding-a-checkmarx-one-build-step-in-teamcity.md)

**Azure DevOps:** [Setting up a Proxy Pipeline Variable](checkmarx-one-azure-devops-plugin/creating-checkmarx-one-pipelines-in-azure/creating-a-checkmarx-one-pipeline-using-a-pre-configured-task.md)

**Jenkins:** [Setting up a Proxy Environment Variable](checkmarx-one-jenkins-plugin/checkmarx-one-jenkins-plugin---installation-and-initial-setup/configuring-global-settings.md)

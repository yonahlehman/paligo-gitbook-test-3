# CI/CD Integrations

We provide specialized plugins to enable seamless integration of Checkmarx One with the following popular CI/CD platforms:

- [Jenkins](checkmarx-one-jenkins-plugin/README.md)
- [TeamCity](checkmarx-one-teamcity-plugin/README.md)
- [GitHub](checkmarx-one-github-actions/README.md)
- [Azure DevOps](checkmarx-one-azure-devops-plugin/README.md)
- [Maven](checkmarx-one-maven-plugin.md)

In addition, we support integration of Checkmarx One using our CLI Tool for the following platforms:

- [Bitbucket Pipelines](checkmarx-one-cli-integrations-for-cicd/checkmarx-one-bitbucket-pipelines-integration.md)
- [CircleCI](checkmarx-one-cli-integrations-for-cicd/checkmarx-one-circleci-integration.md)
- [GitLab](checkmarx-one-cli-integrations-for-cicd/checkmarx-one-gitlab-integration.md)
- [Bamboo](checkmarx-one-cli-integrations-for-cicd/checkmarx-one-bamboo-integration.md)
- [CodeBuild](checkmarx-one-cli-integrations-for-cicd/checkmarx-one-aws-codebuild-integration.md)
